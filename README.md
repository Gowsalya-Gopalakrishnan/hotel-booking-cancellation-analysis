# 🏨 Hotel Booking Cancellation Analysis

## Overview
Exploratory data analysis of hotel booking data to understand what drives cancellations.

## Tools Used
Python, Pandas, Matplotlib, Seaborn

## What I Did
- Cleaned 119,390 booking records by removing 31,994 duplicates and handling missing values
- Created 11 visualizations to explore booking patterns

## Key Findings
- About 27% of bookings were canceled
- Longer lead times were strongly linked to higher cancellation rates

## Files
- `hotel-booking-cancellation.ipynb` – full analysis notebook

## Dataset
Source: Hotel Booking Demand Dataset (Kaggle)
